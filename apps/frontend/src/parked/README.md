Сховані блоки лендингу. Не підключені до App.tsx.

- FeaturesSection.tsx: чотири картки форматів (Конспект, Переказ, Тест, Терміни)
- HowItWorksSection.tsx: блок «Як це працює» з трьома кроками

Щоб повернути блок, імпортуйте компонент в App.tsx і вставте його всередині <main> перед секцією кабінету. Для HowItWorksSection також поверніть посилання на #how у шапці, мобільному меню та кнопку «Як це працює» в hero.
